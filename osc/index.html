Verbindung

OSC-Ziel

Der Port muss dem OSC-Eingang im Zielprogramm entsprechen (MadMapper: Preferences → OSC). Host ist der Rechner, auf dem das Programm laeuft — laeuft die Bruecke dort mit, genuegt 127.0.0.1.

Feedback

Auf diesem Port hoert die Bruecke auf OSC und reicht alles an das Handy weiter — Regler folgen dann dem Programm. 0 = aus.

NovaStar-Prozessor

Adressen /nova/brightness, /nova/blackout, /nova/freeze, /nova/preset uebersetzt die Bruecke in das TCP-Protokoll des Prozessors (Standard-Port 5200).

Bruecke einrichten

  1. osc-bridge.mjs herunterladen (auf den Rechner mit MadMapper).
  2. Terminal/Eingabeaufforderung im Ordner oeffnen und starten:
    node osc-bridge.mjs
  3. Die Bruecke zeigt eine Adresse wie http://192.168.1.20:8090 — die hier oben eintragen (bzw. am Handy oeffnen).

Node.js ≥ 18 wird benoetigt. Die Bruecke hat keine Abhaengigkeiten und laeuft nur im lokalen Netz.

Monitor

Auf eine empfangene Zeile tippen legt daraus ein Bauteil an — so uebernimmst du Adressen direkt aus MadMapper.

Hilfe

Warum eine Bruecke? OSC laeuft ueber UDP, und das kann kein Browser. Das kleine Node-Programm osc-bridge.mjs auf dem Show-Rechner macht aus den Nachrichten des Handys echte UDP-Pakete — und schickt Feedback zurueck.

Adressen in MadMapper. Am schnellsten per OSC lernen: in MadMapper den Regler auswaehlen, Lernen einschalten, hier den Fader bewegen. Umgekehrt geht es auch: einen Regler in MadMapper bewegen, die Adresse taucht im Monitor auf, antippen — fertig ist das Bauteil.

Live bedienen. Regler ziehen relativ, ein Antippen aendert nie einen Wert. Seitlich ausweichen macht den Griff fein.

Bearbeiten. Kachel ziehen verschiebt sie, die Ecke unten rechts zieht sie auf, kurzes Antippen oeffnet die Einstellungen des Bauteils. Liegt am Zielplatz schon etwas, weicht es nach unten aus.
